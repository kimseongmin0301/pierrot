주장 분해 결과 검토

로컬 모델이 만든 금융 답변 10건을 검증 가능한 주장 단위로 나눈 결과입니다. 원문에서 밑줄이 그어진 구간은 주장으로 추출된 부분이고, 밑줄이 없는 구간은 어떤 주장에도 포함되지 않은 부분입니다. 누락이 있다면 그곳에 있습니다.

검토할 때 볼 것

  1. 누락 — 원문에서 밑줄이 없는 구간에 검증 가능한 진술이 남아 있는지. 누락된 주장은 뒤 단계에서 영원히 검증되지 않으므로 가장 치명적입니다.
  2. 자립성 — 주장 하나만 떼어 읽어도 무엇에 대한 이야기인지 알 수 있는지. "그것은 5% 올랐다" 같은 문장은 검증 단계에서 조회 대상을 특정할 수 없습니다.
  3. 값 보존 — 원문의 수치와 날짜가 그대로 옮겨졌는지. 분해 모델이 틀린 값을 고쳐 버리면 검증할 환각 자체가 사라집니다.
  4. 유형 분류 — NUMERIC / PRICE / NARRATIVE 가 실제 검증 도구와 맞는지. 잘못 붙으면 엉뚱한 도구로 조회하게 됩니다.
  5. 지어내기 — 빨간 테두리가 붙은 주장의 근거 문장이 원문과 실제로 같은 뜻인지.
